# Reunee

Landing page responsiva criada para centralizar a presença digital do streamer **Reunee**. O projeto reúne links para canais, conteúdo e plataformas em uma interface leve, com identidade visual própria.

## Destaques

- Layout responsivo para celular e desktop
- Links organizados para plataformas e redes sociais
- Botão de compartilhamento com Web Share API e fallback para área de transferência
- Favicon personalizado e interface sem dependências externas

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Como executar

Como é um projeto estático, basta abrir o arquivo `index.html` no navegador.

## Estrutura

- `index.html` — página, estilos e comportamento do projeto
- `favicon.svg` e `favicon.png` — ícones do site
